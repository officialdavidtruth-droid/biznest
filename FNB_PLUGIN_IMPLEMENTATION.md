# BizNest FnB Plugin

Adds a dedicated Food & Beverage operating workspace to the BizNest app marketplace.

## Scope
- Menu and catalog control
- POS and order operations
- Table/reservation visibility
- Kitchen operations
- Inventory health
- Customer and delivery shortcuts
- Marketing growth shortcut
- Live operational metrics from existing BizNest data

The plugin uses the existing Order, Product, InventoryItem and Booking models; no database migration is required for this first release.
